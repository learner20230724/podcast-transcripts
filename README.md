# 播客文稿库

按播客名称和单期节目名称整理可阅读、可打印的文字稿。

## 目录

```text
播客名称/
└── 每期节目名称/
    ├── 全文_原始转写.txt
    ├── 全文_校读版.txt
    └── 全文_校读版.docx
```

- **原始转写**：自动语音识别结果，可能有错字、断句错误或缺失标点。
- **校读版**：在原始转写基础上由 AI 逐段校读，补充标点和自然段，保留全文及口语、重复表达；只订正有把握的明显识别错误，不等同于逐字核对音频。
- **Word 文档**：适合打印的全文校读版，标题使用宋体，正文前仅保留节目时长与来源；有可靠时间信息时每 20 分钟设置一处近似时间索引。

每期文稿分别生成，尚未完成的文件不会以空文件占位。来源和节目时长见对应文稿。

## 内容与使用

播客内容版权归原作者及相关权利人所有。文字可能存在识别或校读错误，应以原节目为准；本仓库不对第三方节目内容授予开源许可。

仓库仅收录上述纯文本与 Word 文档，不收录音频、下载缓存、处理数据库、内部记录或转写程序。
